# Asset Proyek Rumah Bunga Cirebon

Masukkan screenshot proyek dengan struktur dan nama berikut:

```text
public/projects/rumah-bunga-cirebon/
|-- cover.png
`-- gallery/
    |-- 01.png
    |-- 02.png
    `-- 03.png
```

Rekomendasi isi:

- `cover.png`: halaman beranda, tampilan desktop.
- `gallery/01.png`: halaman koleksi dan filter kategori.
- `gallery/02.png`: halaman detail produk.
- `gallery/03.png`: tampilan mobile atau alur pemesanan WhatsApp.

Rekomendasi teknis:

- Rasio: `16:10` atau `16:9` untuk semua gambar.
- Resolusi minimum: `1600 x 1000 px`.
- Format: PNG untuk screenshot UI yang tajam.
- Jangan mencampur rasio portrait dan landscape dalam satu slider.
- Hindari data pelanggan, nomor telepon pribadi, atau informasi sensitif.
